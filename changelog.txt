Done:

Features:
- New crash handler. If an error occurs, Geomancer will be forced to shut down
	- You will get the chance to try and export whatever is currently loaded into a newly-created directory
	- The log file will also be copied over to this directory, so it won't be lost on reastart.
- Add event and Add multiple events dialogs:
	- The start and offset times can now be entered in beats in addition to samples and seconds
		- This only considers the first tempo section in the map
		- The tempo section's start time is taken into account. Beat 0 corresponds to it (or the next beat if it's negative), beat 1 is the first beat after the start of the tempo section
			- This means entering an integer as an event start (beats) should result in the signal being on-beat
			- Offset in beats just uses the length of a beat as a unit and ignores the start time.
	- Repeats can now be created in groups of multiple events sent on the same sample
- New Tempo section dialog:
	- You can set tempo in seconds/beat (how long each beat lasts in seconds)
	- Start of the tempo section can be set in samples, seconds and beats
		- That last one means "how many beats of the previous tempo section after the start of the previous tempo section"
			- It is only available if the tempo section you're editing is not currently the first one
			- You can set this to a negative number, though this will change the ordering and the value will be recalculated with respect to the (newly) previous tempo section
	- Newly added tempo sections are now set to start two beats after the previous one
	- Start time cannot be lower than negative samples per beat
	- There is now a hard limit of 6000 BPM.
- Obstacles now fade when near the camera so they don't obstruct the view
	- You can cycle between this, hidden and visible always in the view settings in the top right corner
	- Transparent models (props, colliders, obstacles) sometimes render in wrong order. I'll see about fixing that later. Transparency is hard =/
- You can now pick from colours present in the map to set the lobby colours
